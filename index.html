I will do it tomorrow

Data Storytelling with CHA-Inspired Clustering

1) The Problem

"I will do it tomorrow."

It sounds harmless, but this pattern repeats and builds stress over time. We use data to separate different procrastination behaviors, then match each profile to a practical solution.

Prepared by: Meddahi Salsabil and Houari Manel

2) Dataset & Preprocessing

  • Dataset: procrastination_study_20k.csv (20,000 rows)
  • Target: 5 procrastination clusters (personas)
  • Categorical features encoded with OneHotEncoder
  • Numeric features scaled with MinMaxScaler
  • Missing values handled (median for numeric, "Unknown" for categorical)

Cluster Distribution

Balanced coverage across all five procrastination profiles.

3) Methodology

  • CHA-inspired approach: chi-square feature selection + entropy decision tree
  • Pipeline: Preprocess → SelectKBest(chi2) → DecisionTreeClassifier
  • Train/Test split: 80% / 20% with stratification
  • Evaluation using accuracy, confusion matrix, confidence distribution

9) Solutions by Cluster + Prediction

Anxious Avoider: Break high-stakes work into low-risk micro-steps + anti-perfection checklist.

Distracted Scroller: App blockers + focused sessions + remove notifications during deep work.

Selective Procrastinator: Pair disliked tasks with rewards and strict time boxing.

Thrill Seeker: Create artificial mini-deadlines and public accountability checkpoints.

Tired One: Energy-first planning (sleep, breaks, task-energy matching).

10) Final Takeaways

  • Procrastination is not one behavior; it is multiple distinct patterns.
  • Our CHA-inspired model captures those patterns with strong predictive quality.
  • Best interventions are persona-specific, not one-size-fits-all.
